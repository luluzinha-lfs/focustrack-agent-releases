# FocusTrack Releases

Repositório público usado exclusivamente para distribuir artefatos oficiais do FocusTrack para clientes.

## Produtos publicados

- FocusTrack Agent
- FocusTrack Ponto

Este repositório **não contém o código-fonte do FocusTrack**. Ele armazena apenas pacotes de instalação, checksums, notas de release e metadados de proveniência aprovados para distribuição.

## Integridade

Cada release deve publicar:

- pacote versionado;
- `SHA256SUMS.txt`;
- notas de release;
- referência ao commit-fonte validado quando aplicável.

Releases existentes não devem ser sobrescritas. Uma nova alteração de binário exige nova versão/tag.
